# D9 — NICHE MASTERY FIT (our home arena: does the agent measurably improve?)

## Objective
Prove the leveling loop makes Hermes better at serving Tuan: correction
rate down, first-try task success up, preference adherence up — measured
on real usage, not asserted.

## 1. RESEARCH
Define the three mastery metrics precisely from available signals:
corrections/turn (frustration phrases), tool-error rate/turn, JIT recall
hit feedback. Establish that each is measurable from ledger+episodes.

## 2. MEASURE BASELINE
First 30 days of production use: record the three metrics weekly. This
baseline is sacred — later claims divide by it.

## 3. PLAN
Interventions that move the metrics: conduct-block tuning, quest
targeting of weak spots, recall improvements. One intervention at a
time (X-style A/B discipline at personal scale: 2-week windows).

## 4. BUILD
Only the planned intervention. Keep everything else frozen during the
window so effects attribute cleanly.

## 5. AUDIT checklist
- [ ] Metric movement computed, not eyeballed (paste numbers).
- [ ] Confounders listed (model switches, task mix changes).
- [ ] Negative results reported honestly (no movement = finding).

## 6. QA gates
Full suite + safety matrix + metric log committed.

## 7. SCORE rubric
- 0-59: no mastery metrics defined.
- 60-79: metrics defined + baseline recorded.
- 80-94: + one intervention with measured improvement.
- 95-100: + sustained improvement over 90 days, two interventions.
